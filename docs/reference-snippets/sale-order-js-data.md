# Изменение данных JS оформления заказа

**Источник:** `_LIB/Кастомизация $arResult для sale.order.ajax.txt` в [ASDAFF/code_store](https://github.com/ASDAFF/code_store).

## Идея

Штатный компонент `sale.order.ajax` формирует структуру данных, которая передаётся клиентскому JavaScript для отображения корзины и оформления заказа. В некоторых проектах требуется дополнить или скорректировать эту структуру, не редактируя файлы ядра и штатный `order_ajax.js`.

В архивной заметке для этого использовалось событие `OnSaleComponentOrderJsData`: например, чтобы добавить в строку товара URL изображения, вычисленный по данным основного товара, если в корзине находится торговое предложение.

## Что важно сохранить

- Не изменять файлы ядра и штатного шаблона компонента.
- Изменять только конкретные поля структуры, необходимые интерфейсу.
- Для SKU учитывать связь предложения с родительским товаром.
- Проверять, что исходный элемент, изображение и нужные поля действительно существуют.
- Формировать корректный публичный URL изображения штатными средствами Битрикс.

## Что нельзя переносить буквально

Архивный пример использует старый стиль регистрации обработчика, глобальную функцию и вспомогательную функцию получения изображений, не определённую в самом фрагменте. В цикле также не проверяется результат получения информации о родительском товаре, а временный массив изображения формируется без гарантии наличия первого элемента.

Перед применением нужно сверить название события, формат аргументов и момент вызова с исходным кодом компонента в установленной версии модуля `sale`. Не следует предполагать, что старый callback с передачей массива по ссылке совместим с современным контрактом события.

## Связь с текущей библиотекой

В проекте уже есть D7-классы для корзины и создания заказа: [библиотека Sale](../../library/sale/README.md). Эта заметка не предлагает создавать второй механизм оформления заказа. Она фиксирует отдельную точку расширения штатного компонента для проектов, где продолжает использоваться `sale.order.ajax`.

**Статус:** идея сохранена; универсальная реализация и интеграционный тест на установленном ядре не создавались.
