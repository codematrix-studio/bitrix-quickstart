# Справочные идеи из code_store

Материалы извлечены из архивного репозитория [ASDAFF/code_store](https://github.com/ASDAFF/code_store). В репозитории были заметки и рабочие фрагменты по 1С-Битрикс, Aspro и PHP.

Перенесены только четыре идеи, которые могут пригодиться в новых задачах:

- [Изменение данных JS оформления заказа](sale-order-js-data.md) — расширение данных штатного `sale.order.ajax`.
- [Диапазон цен товара и торговых предложений](catalog-price-range.md) — поддержание минимальной и максимальной цены для каталога.
- [Копирование записей HL-блока](highload-block-copy.md) — перенос данных между однотипными HL-блоками.
- [SVG-сектор на vanilla JavaScript](svg-sector.md) — компактная отрисовка и анимация кругового индикатора.

## Правила использования

Это конспекты идей, а не готовые к подключению реализации. Исходные фрагменты написаны для старых версий PHP и Битрикс, местами используют устаревший API и не содержат достаточных проверок.

Перед реализацией:

1. Проверить актуальное API целевой версии Битрикс и PHP.
2. Не переносить исходный код буквально.
3. Для операций записи проверять права, входные данные и результат каждого действия.
4. Учитывать нагрузку, кеширование и повторный вызов обработчиков.
5. Проверить лицензию и происхождение стороннего кода, если используется не только идея, но и сам исходник.

В проекте уже есть D7-слои для Sale и HL-блоков. Перед созданием нового класса сначала изучите соответствующую библиотеку и расширяйте её только при наличии общего сценария.
