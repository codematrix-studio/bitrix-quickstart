# SVG-сектор на vanilla JavaScript

**Источник:** `_LIB/Draw svg circle/sector.es6.js` в [ASDAFF/code_store](https://github.com/ASDAFF/code_store).

## Идея

Небольшой класс `Sektor` строит SVG-круг и сектор по углу, поддерживает режим дуги и анимацию изменения угла через `requestAnimationFrame`.

Возможные применения:

- круговой индикатор выполнения;
- визуализация доли или прогресса;
- небольшой декоративный графический элемент без подключения библиотеки диаграмм.

## Что представляет интерес

- Использование SVG вместо canvas для простой геометрии.
- Расчёт координат дуги через синус и косинус.
- Анимация через `requestAnimationFrame`.
- Отсутствие зависимости от jQuery.

## Что проверить при переписывании

- Наличие целевого DOM-элемента и корректность входных параметров.
- Нормализацию углов, включая отрицательные значения и полный круг.
- Корректное поведение при нулевом и полном угле.
- Экранирование/безопасную установку атрибутов SVG: не вставлять пользовательские значения через `innerHTML`.
- Отмену предыдущей анимации при запуске новой.
- Доступность: текстовое значение прогресса и подходящие ARIA-атрибуты, если индикатор передаёт смысловую информацию.

## Ограничения исходника

Исходный класс вставляет SVG-разметку через `innerHTML`, не проверяет найденный элемент и не валидирует параметры. Он обрабатывает угол больше 360 градусов, но не нормализует отрицательные значения. Также не предусмотрено управление конкурирующими анимациями.

## Рекомендуемое направление

Если такой элемент понадобится в интерфейсе, реализовать компактный независимый ES-модуль с созданием SVG-узлов через DOM API, проверкой параметров и управляемой анимацией. Не добавлять его в общую библиотеку до появления реального повторного использования.
