# План развития библиотеки

План задаёт порядок работ, а не обещает готовность решений. Каждый пункт переводится в реализацию после уточнения контракта и тестовых сценариев.

- [x] Добавить шаблон карточки решения и правила статусов.
- [ ] Настроить общие проверки качества и тестовый bootstrap без зависимости от ядра БУС.

## Этап 2. Первые решения

1. **IBlock Element Service** — безопасная работа с элементами инфоблока: выборка, получение, создание/обновление с явными ограничениями.
2. **Sale Basket Service** — операции с корзиной текущего пользователя с проверкой владельца и корректной работой с API модуля sale.
3. **Secure AJAX Handler** — шаблон AJAX-обработчика с проверкой сессии, авторизации, прав на объект, валидацией и единым форматом ответа.

Для каждого решения сначала фиксируются API и threat model, затем код и тесты.

## Этап 3. Расширение

- Каталог: разделы, SKU, умный фильтр.
- Продажи: заказы, скидки, доставка и оплата.
- Инфоблоки: свойства, разделы, HL-блоки.
- Пользователи: регистрация, авторизация, профиль и пользовательские поля.
- Интеграции: REST API, webhooks, обмен с 1С и внешние сервисы.
- Система: кеш, агенты, события, файлы и логирование.
- Frontend: формы, AJAX и JavaScript-утилиты.

## Правило готовности

Решение не считается готовым только потому, что оно написано. До статуса Tested нужны воспроизводимые автономные тесты; до Bitrix Verified — проверка на реальном ядре и документированная конфигурация.
