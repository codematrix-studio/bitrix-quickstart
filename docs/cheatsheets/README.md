# Шпаргалки разработчика

Краткие практические справочники для повседневной работы. Команды приведены для современных версий Git, Bash, Node.js и npm; отдельные возможности зависят от версии установленного инструмента.

## Разделы

- [Git](git.md) — рабочий цикл, ветки, синхронизация, просмотр и безопасная отмена изменений.
- [Bash](bash.md) — навигация, файлы, поиск, перенаправление вывода и полезные сочетания команд.
- [npm](npm.md) — зависимости, lock-файл, скрипты и диагностика пакетов.
- [GitHub](github.md) — ссылки на код, сравнение изменений, Pull Requests и навигация по интерфейсу.

## Принципы использования

- Перед командами, меняющими историю Git или удаляющими файлы, проверяйте текущую директорию и состояние репозитория.
- Не запускайте команды из примеров вслепую: адаптируйте пути, имена веток и пакетов.
- Не копируйте пользовательские shell-конфиги целиком: сначала проверьте каждую команду и переменную окружения.
- В проектах фиксируйте lock-файл и используйте версии инструментов, согласованные с командой и CI.
- Шпаргалки не заменяют официальную документацию и проверку совместимости.
