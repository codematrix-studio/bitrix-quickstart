# Bash и командная строка

Примеры подходят для Bash (Linux, macOS, Git Bash). В Windows пути Git Bash обычно имеют вид `/c/Users/name`; в PowerShell синтаксис некоторых команд отличается.

## Где я и что находится рядом

```bash
pwd                 # текущая директория
ls                  # содержимое
ls -la              # включая скрытые файлы, подробный список
cd project          # перейти в подкаталог
cd ..               # на уровень выше
cd ~                # домашний каталог
cd -                # предыдущая директория
```

Используйте Tab для автодополнения путей и имён. Кавычки защищают пробелы и специальные символы в именах.

## Каталоги и файлы

```bash
mkdir project
mkdir -p project/{src,tests,docs}
touch README.md
cp source.txt backup.txt
cp -r source-dir/ backup-dir/
mv old-name.txt new-name.txt
mv file.txt archive/
rm file.txt
rmdir empty-dir
```

**Опасные операции:** `rm -rf` удаляет рекурсивно без запроса. Перед удалением проверяйте `pwd`, путь и содержимое каталога. Не подставляйте непроверенные переменные в команды удаления.

## Чтение и поиск

```bash
cat README.md
less README.md
head -n 20 file.log
tail -n 50 file.log
tail -f file.log
grep -n "needle" file.txt
grep -Rni --exclude-dir=.git "needle" .
find . -type f -name "*.php"
find . -type f -iname "*config*"
```

Для сложных шаблонов `grep -E`; для поиска без учёта регистра — `-i`. В больших проектах исключайте каталоги зависимостей и сборки.

## Перенаправление и конвейеры

```bash
command > output.txt       # перезаписать файл выводом
command >> output.txt      # добавить вывод в конец
command 2> errors.txt     # перенаправить stderr
command > all.txt 2>&1    # объединить stdout и stderr
command1 | command2       # передать вывод первой команды второй
```

Оператор `&&` запускает следующую команду только при успешном завершении предыдущей; `||` — при ошибке. Точка с запятой `;` запускает следующую команду независимо от результата предыдущей.

## Полезные системные команды

```bash
which php
php -v
php -m
node --version
npm --version
df -h
du -sh .
ps aux
```

Набор команд и доступные ключи зависят от ОС и установленного набора утилит.

## Переменные и алиасы

```bash
PROJECT_DIR="$HOME/projects/site"
cd "$PROJECT_DIR"

alias ll='ls -la'
alias gs='git status --short'
```

Временная переменная действует в текущем shell. Для передачи переменной дочерним процессам используйте `export NAME=value`. Алиасы можно добавить в пользовательский `.bashrc` или `.bash_profile` в зависимости от способа запуска shell.

Не копируйте чужие `.bashrc` / `.bash_profile` целиком: там могут быть специфичные пути, автоматический запуск процессов, изменение PATH и команды, влияющие на окружение.

## Перед выполнением команды

- Проверьте текущую директорию: `pwd`.
- Заключайте переменные и пути в кавычки: `"$PATH"`.
- Сначала используйте режим просмотра/симуляции, если утилита его поддерживает.
- Не запускайте скачанные shell-скрипты напрямую через `curl | bash`, пока не проверили источник и содержимое.
