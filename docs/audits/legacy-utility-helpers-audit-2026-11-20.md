# Аудит legacy-вспомогательных утилит и Itsfera

**Источник:** ASDAFF/bitrix.quickstart, ветка master  
**Файлы:** Itsfera.php, HelperFunctions.php, Tools/CDebug.php, Tools/CSoloTools.php  
**Дата проверки:** 2026-11-20  
**Статус:** Itsfera/CDebug/CSoloTools просмотрены полностью; HelperFunctions (2182 строки) — выборочный проход по наиболее рискованным методам, полный аудит файла остаётся открытым. Перенос не выполнялся.

## 1. Itsfera.php

Класс используется компонентами mht/offers и mht/brands. Подтверждены вызовы getBrandByCode(), getIBlockIDByElemProp() и getSectionIDByElemProp(); последние два вызываются из component.php с фиксированными значениями свойства SAYT_NOVINKA и значения Да.

### Найденные проблемы

1. **SQL injection в двух методах.** getSectionIDByElemProp() и getIBlockIDByElemProp() конкатенируют $propName и $propValue непосредственно в SQL. Параметры не экранируются и не передаются через параметры запроса. Текущие найденные вызовы в offers используют литералы, поэтому конкретная эксплуатируемая точка через этот компонент не подтверждена; сам публичный контракт класса небезопасен.
2. **Коллизии ключей кеша.** Ключ строится как md5("method" . $propName . $propValue) без разделителей/структурированного кодирования. Разные пары аргументов могут иметь одинаковую склеенную строку и получить чужой результат.
3. **Нет теговой инвалидации кеша.** Результат зависит от свойств и элементов инфоблока, но кеш живёт два часа без привязки к тегам инфоблока/свойств.
4. **Зависимости не подключаются единообразно.** getSubBrandsByBrandCode() обращается к CIBlockElement и глобальной getIBlockIdByCode() без проверки загрузки модуля.
5. **Неполные контракты.** Входные аргументы не типизированы; при пустой выборке методы возвращают false или массив в разных случаях.
6. **SEO-кеш не учитывает весь контекст.** getSeoParamsForIblock() строит cache ID только по IBLOCK_ID, хотя результат вычисляется на основе переданного массива IBLOCK и шаблонов; не включены site/language контекст и версия шаблонов.

**Решение:** не переносить как есть. SQL переписать через ORM/query builder с параметрами; кеш — с однозначным ключом и теговой инвалидацией; контракты и зависимости сделать явными.

## 2. HelperFunctions.php — выборочный проход

Файл содержит 2182 строки и объединяет разнородные методы. Полный проход по всем функциям и точкам использования не завершён.

### Подтверждённые проблемы

1. **Произвольное выполнение shell-команды.** Метод syscall($command) выполняет popen("($command)2>&1", 'r') без ограничения команд/аргументов. Точек вызова в репозитории по точному поиску не найдено, но метод опасен при передаче любых пользовательских данных.
2. **Устаревшая и некорректная SQL-очистка.** filterString() использует mysql_escape_string(), удалённую из PHP 7+, без привязки к соединению/кодировке. В PHP 7+ вызов приводит к Error; HTML-экранирование не является SQL-экранированием и не должно смешиваться с хранением.
3. **Ошибка в priceFormat().** Метод принимает $str, но передаёт в number_format() неопределённую переменную $price; результат не зависит от аргумента.
4. **Небезопасный путь логирования.** logToFile() конкатенирует переданный $fileName с P_LOG_DIR без нормализации/ограничения каталога и не проверяет fopen(); при внешнем контроле имени возможна запись за пределами каталога логов.
5. **Генерация PHP-файла на лету.** cp_get_language_message() создаёт/переписывает phrases.php и записывает новый ключ в исходный PHP-файл. Каталоги создаются с правами 0777, файл touch() — 0666; создаётся риск небезопасных прав и порчи рабочего файла. Используется короткий PHP-тег в генерируемом содержимом.
6. **Ошибка обработки исключения в convertExcelIntoCsv().** Catch получает $re, но в die() используется неопределённая $e. В finally проверяется, что $objPhpExcel является экземпляром PHPExcel_IOFactory, хотя IOFactory::load() возвращает объект книги; очистка worksheets поэтому не выполняется. В методе также используется die() вместо нормального результата.
7. **Не проверяется результат файловых операций.** logToFile(), convertExcelIntoCsv() и ряд вспомогательных методов не проверяют результат открытия/записи до использования.
8. **Неоднородная ответственность.** В одном классе смешаны Sale, инфоблоки, форматирование, Excel, логирование, SEO, параметры URL, глобальные функции и shell. Это затрудняет тестирование и безопасное использование.

**Решение:** не переносить фасад. Разбирать методы по одному только после подтверждения фактического использования; syscall удалить либо заменить allowlist-командами, filterString разделить на контекстную валидацию и параметризованные запросы, логирование ограничить выделенным каталогом.

## 3. Tools/CDebug.php

1. **Отображение данных без HTML-экранирования.** print_r($data) вставляется непосредственно в HTML <pre>. Если в диагностируемых данных есть пользовательский HTML/JS, вывод может выполнить его в браузере.
2. **Удалённый модификатор /e.** preg_replace() использует модификатор /e, удалённый в PHP 7. Этот участок не совместим с актуальными версиями PHP и не должен заменяться на eval.
3. **Внешние ассеты по HTTP.** CodeMirror загружается с codemirror.net по HTTP; это небезопасно и зависит от устаревшего внешнего ресурса.
4. **Глобальные обработчики клавиатуры.** echo_r() перезаписывает document.onkeydown, что конфликтует с другими скриптами страницы.
5. **Нет явной проверки окружения.** Диагностический вывод/подсветка доступны как обычные методы без ограничения режима разработки.

**Решение:** не переносить; для отладки использовать штатные инструменты/логгер, а вывод структурированных данных обязательно экранировать.

## 4. Tools/CSoloTools.php

1. **Удалённый модификатор /e.** html2line() использует preg_replace с /e; в PHP 7+ такой код не работает.
2. **Слабая генерация пароля.** generate_password() использует rand(), не криптографический генератор. Не использовать для паролей/токенов.
3. **Частичная запись свойств без транзакции.** update_eiblock_properties() вызывает SetPropertyValues() для каждого свойства отдельно, не проверяет результат каждой записи, затем отдельно обновляет элемент. Ошибка посередине оставляет частично изменённое состояние; возвращаемое true отражает только Update элемента.
4. **Смешение получения и изменения структуры инфоблока.** AddNewProperty() может создавать свойства во время выполнения и возвращать ID, при этом нет блокировки/транзакции от параллельного создания одинакового кода.
5. **Глобальный контекст для цепочки getibc/getibc2/getibc3.** Последовательность вызовов зависит от глобального массива параметров; повторное/вложенное использование может перезаписать контекст.
6. **Проверка лицензии/модуля через includeSharewareModule().** Используется специфичный метод загрузки модуля, который может вернуть false в зависимости от лицензии; контракт не объяснён и не проверяется везде.
7. **Слабая типизация и PHPDoc.** Большинство методов не описывают точные типы/форматы входных данных и результата.

**Решение:** не переносить как набор. Нужные операции выделять в сервисы с явными аргументами, транзакциями и безопасным генератором паролей.

## Дополнение после расширенного прохода по HelperFunctions.php

Проверены дополнительные группы методов и участки файла:

1. **Пагинация формирует href из REQUEST_URI без HTML-экранирования.** В paginator() путь берётся из $_SERVER['REQUEST_URI'] и напрямую вставляется в атрибут href. Также ветка для страниц меньше 3 использует $last до инициализации; границы page/sizePage не нормализуются.
2. **getBasket() декодирует HTML вместо безопасного экранирования.** PREVIEW_TEXT обрабатывается через htmlspecialcharsBack(), который снимает HTML-сущности. Функция возвращает данные для последующего вывода; вызывающий код должен отдельно экранировать текст, но контракт этого не гарантирует.
3. **text4JS() не является полноценным JS-экранировщиком.** Удаляются CR/LF и экранируется только заданная кавычка; обратные слеши и другие управляющие символы не обрабатываются. text4flash() оставляет часть HTML-тегов и не санитизирует атрибуты/схемы ссылок.
4. **getIBlocks() отключает проверку прав.** В фильтр CIBlock::GetList() жёстко добавлено CHECK_PERMISSIONS => N. При использовании в публичном контексте метод возвращает активные инфоблоки без проверки доступа.
5. **scandirs() рекурсивно обходит произвольный путь.** Нет проверки успешности opendir(), ограничения глубины/количества файлов и защиты от циклических символических ссылок.
6. **FormatFilesize() вычисляет единицу по длине строки, а не по числовому размеру.** Для некоторых значений/форматов результат будет неверным.
7. **getNews() использует unserialize() на данных кеша.** Это не клиентская cookie, а внутренний кеш Bitrix; риск ниже, однако безопаснее ограничить классы и валидировать ожидаемую структуру.

Полный аудит 2182 строк всё ещё не закрыт: эти замечания расширяют выборочную проверку, но не подтверждают отсутствие других дефектов.
