# CodeMatrix STUDIO — библиотека решений для 1С-Битрикс

Библиотека предназначена для повторного использования проверенных PHP-решений в проектах на 1С-Битрикс: Управление сайтом (БУС).

Цель — не коллекция случайных сниппетов, а набор небольших автономных компонентов с понятными контрактами, документацией, примерами и проверками.

## Принципы

- PHP 8.1+ как базовая целевая версия; совместимость с конкретными версиями PHP и БУС указывается в каждом решении.
- D7 — предпочтительный API для новых решений. Старые API допускаются только при обоснованной необходимости и с явной пометкой.
- Безопасность по умолчанию: проверка прав на каждый объект, валидация входных данных, CSRF-защита для изменяющих запросов, безопасная работа с файлами и SQL.
- Никаких скрытых побочных эффектов при подключении файлов.
- Небольшая ответственность и явные зависимости.
- Русскоязычная документация и PHPDoc.
- Автономные тесты обязательны там, где это возможно; интеграция с ядром БУС проверяется отдельно.

## Статусы решений

| Статус | Значение |
| --- | --- |
| Draft | Черновик; использовать в production без собственной проверки нельзя |
| Reviewed | Проведено ревью кода и контракта |
| Tested | Автономные тесты пройдены в заявленном окружении |
| Bitrix Verified | Дополнительно проверено на реальном ядре БУС в указанной конфигурации |

Статус всегда сопровождается версиями PHP и БУС, на которых выполнялась проверка. Непроверенное решение не маркируется как Tested или Bitrix Verified.

## Как добавить решение

1. Выбрать подходящий раздел и создать отдельную директорию решения.
2. Описать назначение, ограничения, требования и пример использования в README.
3. Реализовать минимальный публичный API с явными типами и PHPDoc.
4. Добавить проверки входных данных, прав доступа и ошибок.
5. Добавить автономные тесты и, если требуется, сценарий интеграционной проверки в БУС.
6. Провести ревью и указать фактический статус.
