# Продажи

- [Sale Basket Service](basket-service/README.md) — корзина текущего FUSER на текущем сайте через D7 Sale.

## Уже реализовано в классовой библиотеке

- `Project\\Bitrix\\Sale\\BasketManager` — добавление, изменение количества, удаление и чтение корзины текущего FUSER.
- `Project\\Bitrix\\Sale\\BasketHandler` — фасад с ограниченным входным контрактом и массивами-снимками вместо изменяемых объектов D7.
- `Project\\Bitrix\\Sale\\OrderManager` — создание заказа из корзины пользователя, установка свойств по символьным кодам, проверка обязательных полей и доступности служб доставки/оплаты.
- `Project\\Bitrix\\Sale\\QuickOrder` — создание заказа из отдельной временной корзины.
- `Project\\Bitrix\\Sale\\QuickOrderInput` — валидация входных данных быстрого заказа.

Подробные контракты и ограничения описаны в [README классов Sale](../../local/php_interface/classes/Bitrix/Sale/README.md).

## Что пока не является готовым решением

HTTP/AJAX endpoint для оформления заказа, редактирование уже созданного заказа, универсальная настройка доставок/платёжных систем и бизнес-правила скидок не входят в перечисленные сервисы. Их нельзя считать реализованными только потому, что библиотека умеет создать заказ.

Для этих сценариев отдельно проектируются авторизация и проверка владельца заказа, CSRF, идемпотентность, актуальность цен/скидок, правила конкретного магазина и обработка повторных запросов. Идентификаторы типа плательщика, доставки и оплаты должны проверяться на сервере по настройкам и ограничениям заказа, а не приниматься как доверенные значения из браузера.
