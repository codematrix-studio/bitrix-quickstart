# Инфоблоки и HL-блоки

Новые реализации ориентируются на D7 API. Создание структуры инфоблоков/HL-блоков выполняется только явной установочной операцией, не при подключении файла.

- [IBlock Element Service](element-service/README.md) — доступ к элементам через D7 ORM с отдельной границей авторизации.

Разделы, свойства и HL-блоки будут добавляться отдельными решениями.
