# Каталог

Планируемые решения: элементы и разделы каталога, SKU/торговые предложения, умный фильтр.

Каждое решение должно учитывать права на инфоблоки и элементы, ограничения выборки, allowlist сортировки и корректное кеширование.

Первое решение для работы с элементами инфоблока: [IBlock Element Service](../iblock/element-service/README.md).
