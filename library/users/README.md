# Пользователи

Планируемые решения: регистрация, авторизация, профиль и пользовательские поля.

Обязательны безопасная обработка паролей, защита от CSRF, проверка прав, ограничение раскрытия персональных данных и нейтральные ответы там, где это важно для безопасности.
