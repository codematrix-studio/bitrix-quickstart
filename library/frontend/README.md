# Frontend и AJAX

Планируемые решения: AJAX-обработчики, формы, клиентская валидация и небольшие JavaScript-утилиты.

Клиентская валидация не заменяет серверную. Для вывода данных обязательна контекстная экранизация; для изменяющих запросов — серверная проверка сессии и прав.

Пока готовых решений в этом разделе нет.
