# Тесты библиотеки

Автономные тесты решений размещаются здесь или в согласованной с CI структуре. Они должны запускаться без установленного ядра БУС, если проверяют чистую PHP-логику.

Интеграционные проверки, требующие ядра БУС, базы данных или модулей, отделяются и документируют окружение. Наличие тестовых заглушек не подтверждает совместимость с реальным ядром.

Для каждой уязвимости или ошибки доступа добавляется регрессионный тест на отказ в небезопасном сценарии.
