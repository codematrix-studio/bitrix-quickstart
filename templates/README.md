# Заготовки компонентов и модулей

Каталог содержит стартовые шаблоны для разработки собственных компонентов и модулей 1С-Битрикс.

## Состав

- `components/classic` — минимальный компонент на процедурном API.
- `components/d7` — рекомендуемая заготовка класса компонента на `CBitrixComponent`.
- `components/complex` — каркас комплексного компонента с SEF- и обычной маршрутизацией.
- `modules/basic` — каркас устанавливаемого модуля с автозагрузкой классов.

## Использование

1. Выберите подходящую заготовку.
2. Скопируйте её содержимое в каталог собственного компонента или модуля.
3. Замените все демонстрационные идентификаторы, имена классов, namespace и языковые ключи.
4. Проверьте пути, права, зависимости и версию PHP/ядра Битрикс целевого проекта.
5. Запустите проверку синтаксиса PHP и тесты проекта.
6. Проверьте установку и работу на тестовом сайте с установленным ядром Битрикс.

Заготовки не являются готовыми к установке компонентами или модулями. Это исходные каркасы, которые требуется адаптировать под конкретную задачу.

## Соглашения

- Собственный код размещается в `/local`, а не в ядре `/bitrix`.
- PHPDoc, README и поясняющие комментарии пишутся на русском языке.
- PHPDoc описывает контракт и поведение, а не пересказывает имя метода.
- Не добавляйте зависимости, глобальные обработчики, AJAX-ответы или работу с базой данных без необходимости.
- Не используйте реальные данные, секреты или идентификаторы конкретного сайта в шаблонах.
