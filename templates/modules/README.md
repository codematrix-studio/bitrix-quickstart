# Заготовки модулей

Каталог содержит два уровня заготовок:

- `basic` — минимальный каркас собственного модуля Битрикс с установщиком, автозагрузкой классов и локализацией.
- `advanced` — расширенная заготовка в разработке: постоянные обработчики событий, агенты, внутренние миграции БД и отдельный пример SiteUpdate / Marketplace updater.

Перед использованием замените идентификатор `vendor.module`, namespace `Vendor\\Module`, имя класса установщика и языковые сообщения. Убедитесь, что идентификатор модуля уникален.

В `basic` при неудачном откате установка оставляет модуль зарегистрированным. После устранения причины повторный вызов установщика повторяет идемпотентные этапы и позволяет завершить частичную установку.

Установщик `basic` намеренно не копирует и не удаляет файлы сайта: добавляйте такие операции только при наличии конкретной необходимости и ограничивайте их каталогом своего модуля.

Архитектурное решение и порядок реализации расширенной заготовки: [advanced module template design](../../docs/design/advanced-module-template-2026-11-24.md).
