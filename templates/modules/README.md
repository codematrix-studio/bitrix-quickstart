# Заготовки модулей

Каталог `basic` содержит каркас собственного модуля Битрикс с установщиком, автозагрузкой классов и локализацией.

Перед использованием замените идентификатор `vendor.module`, namespace `Vendor\\Module`, имя класса установщика и языковые сообщения. Убедитесь, что идентификатор модуля уникален.

Установщик намеренно не копирует и не удаляет файлы сайта: добавляйте такие операции только при наличии конкретной необходимости и ограничивайте их каталогом своего модуля.
