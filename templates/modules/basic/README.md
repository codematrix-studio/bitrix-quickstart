# Базовая заготовка модуля

## Структура

- `include.php` — регистрация автозагрузки классов модуля.
- `lib/ExampleService.php` — пример класса сервиса.
- `install/index.php` — установщик и удаление модуля.
- `install/version.php` — версия модуля.
- `lang/ru/install/index.php` — русскоязычные сообщения установщика.

## Настройка

1. Замените идентификатор `vendor.module` на уникальный идентификатор модуля.
2. Переименуйте класс `vendor_module` в соответствии с идентификатором.
3. Замените namespace `Vendor\\Module` на namespace проекта.
4. Измените карту автозагрузки в `include.php`.
5. Заполните название и описание модуля в языковом файле.
6. Добавляйте регистрацию событий, установку таблиц и копирование файлов только при реальной необходимости.

## Важные замечания

Установщик использует штатный контракт `CModule`, поскольку его вызывает механизм установки модулей Битрикс. Не переносите в него бизнес-логику. Операции установки и удаления должны быть идемпотентными и удалять только ресурсы, принадлежащие этому модулю.

После настройки обязательно проверьте установку, повторный запуск установки, удаление и повторную установку на тестовом сайте.
