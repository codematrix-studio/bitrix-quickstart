# Заготовки компонентов

| Каталог | Назначение |
|---|---|
| classic | Минимальный компонент на процедурном API для legacy-проектов |
| d7 | Основной шаблон класса компонента на CBitrixComponent |
| d7-ajax | D7-компонент с Controllerable, POST, CSRF и серверной проверкой прав |
| complex | Маршрутизация списка и детальной страницы в SEF/non-SEF режимах |

Копируйте содержимое выбранной заготовки в `local/components/<пространство>/<имя>/` и замените демонстрационные имена, описание, параметры и контракт результата.

Для новой разработки выбирайте D7. Используйте `d7-ajax`, если компонент действительно предоставляет AJAX-действия. Для изменяющих состояние действий оставляйте POST и CSRF-фильтр, а проверку полномочий выполняйте на сервере для каждого объекта. Заготовка по умолчанию закрывает доступ в `canSubmit()`, пока разработчик явно не реализует политику доступа.

Для complex маршрутизатор определяет страницу и переменные, но не получает данные и не кеширует их. В non-SEF режиме псевдоним ELEMENT_ID задаётся плоским параметром; в SEF режиме псевдонимы обрабатываются отдельно для страницы detail. В текущей версии шаблоны list.php и detail.php являются шаблонами одного комплексного компонента, а не отдельными компонентами. После добавления получения данных определите кеш-контракт для каждой ветки маршрутизации; если страницы будут вынесены в самостоятельные компоненты, перенесите кеширование в них.
