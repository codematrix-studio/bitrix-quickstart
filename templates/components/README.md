# Заготовки компонентов

| Каталог | Назначение |
|---|---|
| `classic` | Минимальный компонент с файлом `component.php` |
| `d7` | Компонент на базе `CBitrixComponent` |
| `complex` | Комплексный компонент с маршрутами списка и детальной страницы |

Каждую заготовку копируйте в каталог собственного компонента внутри `local/components/<пространство>/<имя>/`. После копирования измените техническое имя, описание и параметры компонента.
