# Инфоблоки

## Дерево разделов

Файл [section-tree.php](section-tree.php) показывает, как собрать дерево разделов инфоблока за один проход по результату `CIBlockSection::GetList()`.

Требуется подключённый модуль `iblock`. Перед вызовом задайте ID инфоблока. Фрагмент возвращает массив, не выводит HTML и не меняет данные.

Источник идеи: `local/codes/blank/compilation/sectionTree.php` в [старом репозитории](https://github.com/ASDAFF/bitrix.quickstart).

## Поиск элементов и разделов

Файл [search-elements.php](search-elements.php) адаптирует полезную часть старых `getSearchedElement.php` и `searchElements.php`: поиск по индексу модуля Search с ограничением по инфоблоку и, при необходимости, по разделу.

Функция `searchIblockItems()` принимает поисковую строку, ID инфоблока, ID сайта, необязательный ID раздела и лимит. Возвращает два массива ID: `ELEMENTS` и `SECTIONS`. Префикс `S` в `ITEM_ID` поискового индекса распознаётся как ID раздела.

Пример вызова после подключения Composer autoload и файла:

```php
$result = searchIblockItems(
    'текст поиска',
    12,
    SITE_ID,
    34,
    30
);

// $result['ELEMENTS'] — ID найденных элементов.
// $result['SECTIONS'] — ID найденных разделов.
```

Требуются модули `search` и `iblock`. Функция не выводит результаты и не формирует ссылки. Поисковый индекс должен быть актуальным; ограничение выборки не заменяет полноценную постраничную навигацию.

Перед использованием подключите файл один раз, например через собственный сервис/компонент. Не подключайте демонстрационные файлы глобально из `init.php`.

## Что не перенесено

- `GetPreLinkProducts.php` использует навигацию `nElementID` для получения соседних товаров. Сам сценарий полезен, но поведение зависит от сортировки, привязки к разделу и правил выбора соседних элементов. Универсальный алгоритм без требований конкретного каталога здесь был бы обманчивым.
- `getAllRegions.php` обращается к Location API и языковым связям. Схема и доступность Location зависят от версии модуля Sale и настроек местоположений; пример нужно отдельно сверять на целевой версии.
- `setValueListProperty.php` содержит жёстко заданный ID значения списка `1453` и имя свойства конкретного каталога. В универсальную библиотеку не переносится.
