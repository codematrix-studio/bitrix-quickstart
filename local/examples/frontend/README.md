# Frontend-примеры

В этом разделе адаптированы две идеи из старого `local/codes/blank/frontend/js`: вкладки/переключение панелей и проверка обязательных полей формы.

## UI-паттерны

[ui-patterns.js](ui-patterns.js) содержит два независимых приёма:

- переключение вкладок через `data-tabs`, `data-tab-target` и `data-tab-panel`;
- раскрытие/скрытие блока через `data-toggle-target`.

Используются нативные события браузера, атрибут `hidden` и состояние `aria-selected` / `aria-expanded`. jQuery и Fancybox не требуются. Для вкладок целевые панели должны находиться внутри одного контейнера `data-tabs`.

## Проверка формы

[form-validation.js](form-validation.js) запускает встроенную HTML5-проверку для форм с атрибутом `data-validate`. Используйте стандартные атрибуты `required`, `type="email"`, `minlength` и другие ограничения HTML.

Это только удобство интерфейса. Все данные необходимо повторно проверять на сервере; клиентский JavaScript можно отключить или обойти.

## Что не переносилось из старого JS

- Проверка всех форм на странице каждые 500 мс заменена проверкой по событию отправки конкретной формы.
- Устаревший вызов `$.fancybox.open()` не переносился: Fancybox — внешняя зависимость, а конкретное окно благодарности относится к дизайну сайта.
- Стилизация полей и классы `empty_field` / `disabled` не являются универсальной логикой и должны определяться интерфейсом конкретного проекта.

Источник: `local/codes/blank/frontend/js/lib_code.js` и `myscripts.js` в [старом репозитории](https://github.com/ASDAFF/bitrix.quickstart).
