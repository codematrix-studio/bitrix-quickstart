# Библиотека примеров

Небольшие самостоятельные заготовки для разработчика 1С-Битрикс. Это справочные фрагменты: перед использованием проверьте наличие модулей, расширений PHP, версию ядра и входные данные конкретного проекта.

## Разделы

- [Инфоблоки](iblock/README.md) — построение дерева разделов.
- [Файлы и данные](files/README.md) — чтение CSV и создание ZIP-архива.
- [Компоненты](components/README.md) — структура и жизненный цикл компонента.

## Откуда взяты материалы

При ревизии использован старый репозиторий [ASDAFF/bitrix.quickstart](https://github.com/ASDAFF/bitrix.quickstart), прежде всего каталоги `local/codes/blank/compilation`, `local/codes/blank/components` и `local/codes/blank/frontend/js`.

Переносились не каталоги целиком, а отдельные идеи и фрагменты после проверки и адаптации. Клиентские данные, жёстко заданные ID, тестовые учётные данные, прямые обработчики запросов без защиты и фрагменты с неясными зависимостями не переносятся.

## Правила использования

1. Примеры не подключаются автоматически из `init.php`.
2. Не размещайте исполняемые демонстрационные скрипты в публично доступных URL без авторизации и проверки прав.
3. Для операций изменения данных добавляйте проверку сессии, прав доступа и валидацию входных данных.
4. Не копируйте в рабочий проект тестовые ID, пути и параметры из примеров.
5. Сначала проверьте, нет ли готового класса в `local/php_interface/classes/` — библиотека проекта уже содержит ряд универсальных решений.
