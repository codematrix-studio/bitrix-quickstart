# Файлы и данные

- [csv-to-array.php](csv-to-array.php) — чтение CSV с заголовком и преобразование строк в ассоциативные массивы.
- [create-zip-archive.php](create-zip-archive.php) — рекурсивное создание ZIP из файла или каталога.

Для ZIP требуется расширение PHP `zip`. Архиватор не должен получать произвольные пользовательские пути: ограничьте исходный каталог и путь назначения на уровне вызывающего кода.

Источники идей: `csv_to_array.php` и `createZipArchive.php` из `local/codes/blank/compilation` старого репозитория.
