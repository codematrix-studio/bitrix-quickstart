# Компоненты

В каталоге находится адаптированная заготовка простого компонента на `CBitrixComponent`:

- [class-component.php](class-component.php) — класс компонента с подготовкой параметров, проверкой модуля, кешированием результата и обработкой ошибок;
- [template.php](template.php) — безопасная основа шаблона с доступом к подготовленному `$arResult`.

Это именно примеры для копирования в собственный компонент, а не готовый компонент сайта. Они не подключаются автоматически и не размещаются в `/local/components` без решения разработчика. При создании компонента скопируйте файлы в собственный каталог, добавьте `.description.php`, `.parameters.php` и языковые файлы под нужный сценарий.

## Что проверено в исходнике

В старом проекте есть несколько поколений заготовок. `clear.component.d7` слишком неполон для использования без доработки: короткие PHP-теги, неинициализированное имя шаблона и слабая обработка ошибок. Более содержательный `example/compsimple` показывает структуру компонента, но содержит неиспользуемые обёртки и не демонстрирует аккуратное управление кешем.

Новая заготовка сохраняет практический принцип исходника: наследование от `CBitrixComponent`, разделение логики и шаблона, подготовка параметров и загрузка модуля. При этом код адаптирован под строгий PHP и не содержит привязки к конкретному инфоблоку, магазину или сторонней библиотеке.

Исходные материалы: `local/codes/blank/components` старого репозитория.
