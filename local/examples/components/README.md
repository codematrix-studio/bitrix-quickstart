# Компоненты

Старый проект содержит несколько заготовок компонентов: простые, D7-варианты, комплексные компоненты и шаблоны. Они требуют отдельной проверки на соответствие версии ядра и принятой в проекте архитектуре.

Не копируем их целиком: в старых версиях встречаются устаревшие PHP-теги, нестрогая обработка ошибок, неинициализированные свойства и шаблонные зависимости. Для новых компонентов используйте актуальный API `CBitrixComponent` и проверяйте совместимость с целевой версией PHP.

В текущей ревизии этот раздел служит реестром; готовый компонентный boilerplate будет добавлен после отдельной проверки полного набора файлов и языковых ресурсов.

Исходные материалы: `local/codes/blank/components` старого репозитория.
