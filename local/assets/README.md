# Ресурсы проекта

Каталог содержит общие ресурсы проекта и самостоятельную площадку для предварительной HTML/CSS/JS-верстки до интеграции в шаблон 1С-Битрикс.

## Структура

- `frontend/` — независимая от Битрикс площадка для верстки и проверки страниц в браузере.
- `frontend/index.html` — стартовая страница предпросмотра.
- `frontend/scss/` — исходники SCSS.
- `css/` — скомпилированные CSS-файлы, которые можно подключать в шаблонах Битрикс.
- `js/`, `images/`, `fonts/` — общие JavaScript, изображения и шрифты.

Стили, относящиеся только к отдельному компоненту Битрикс, по-прежнему можно хранить рядом с компонентом.

## Рабочий процесс

1. Начните верстку в `frontend/index.html`, не подключая Битрикс.
2. Редактируйте SCSS в `frontend/scss/`; PhpStorm может автоматически компилировать его в `css/` через File Watcher.
3. Проверяйте результат, открывая `frontend/index.html` в браузере.
4. После утверждения макета перенесите HTML-разметку в шаблон Битрикс и подключите соответствующие CSS/JS/изображения штатными средствами проекта.
5. Продолжайте изменять исходные SCSS: после интеграции они остаются рабочими исходниками, а CSS обновляется компилятором.

Настройка компилятора Sass/SCSS в PhpStorm описана в [руководстве](../../docs/frontend/phpstorm.md). Общий порядок работы — в [документации frontend](../../docs/frontend/README.md).

Сторонние библиотеки не следует складывать сюда без проверки необходимости, совместимости и лицензии.
