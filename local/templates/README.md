# Шаблоны сайта

В этом каталоге находятся заготовки шаблонов сайта и общие шаблоны компонентов.

- `.default/` — общие шаблоны компонентов и шаблоны страниц, используемые как fallback.
- `main/` — основной шаблон сайта. Это стартовая заготовка, которую следует адаптировать под дизайн и требования конкретного проекта.

В `main/components/` размещайте переопределения шаблонов компонентов для основного шаблона сайта. Общие варианты можно хранить в `.default/components/`.

Стили и скрипты подключайте средствами Битрикс и архитектуры конкретного проекта.
